# 可配置保存间隔实施与验收

## 约定

- 设置名为“统计自动保存间隔”，单位秒，默认六十，可设十五至一千八百秒；预设三十秒、一分钟、两分钟、五分钟。
- 字数按原输入口径落账，时长保留十五秒心跳及五分钟空闲阈值；普通变化只更新内存和现有局部图表，不再立即写盘。
- 第一笔待保存变化启动固定期限，持续输入不重置；无变化不写。设置变更、导入、清空、恢复等保护数据边界的操作仍立即保存。
- 后台保存当前时长和未落账编辑；退出通过宿主退出任务队列等待保存，卸载复用同一个任务。失败保留脏状态并重试，状态通知不触发图表查询。
- 强杀、断电、宿主不发退出通知和持续磁盘错误无法承诺零丢失，不为此加入新的高频落盘路径。

## 验收接口

1. 活动服务公开接口与普通文件写入：默认值、合法范围、持续变化固定期限、十五秒有统计无写入、后台立即保存、并发保存串行、失败重试、重复卸载幂等。
2. 设置页公开行为：预设、自定义、非法输入保留原值、保存状态更新和订阅释放。
3. 图表公开刷新接口：保存状态不触发查询，原统计变化继续局部更新。
4. 隔离 Obsidian 真实退出重开：保存间隔五分钟，未到期输入和计时；关闭前确认没有定时写盘，增加受控磁盘延迟，正常关闭实际进程后重开同一仓库，通过公开查询核对最后一批字数、时长和明细，无重复、间隔持久化、图表正常。不得用手动 flush 或插件卸载代替真实关闭。
5. 安装 CMBK 前备份插件、普通统计目录和导出；安装后核对全部数据、原设置、主题、首页与启用清单，只新增默认一分钟设置，不填造样例、不提交或推送。


## 实际退出行为与决定

仅登记异步退出任务在当前宿主的真实窗口关闭中仍可能来不及完成，测试先复现了这个问题。支持本地文件系统的桌面端增加同步最终检查点：在退出回调返回前，写临时文件、刷新文件、原子替换并回读校验；路径必须留在仓库内，包括已有父目录的真实路径检查。移动适配器不调用本地文件系统能力，继续走异步任务和后台保存，实体手机未验收。

退出检查点会封存当前运行；排队的旧快照不能再取得更高版本，进行中的旧版本即使稍后完成也不会覆盖最终记录。未到期的重命名操作也同步保存。常规版本保留两份，退出另留一份最终检查点。

退出用例临时抑制后台保存，让最后数据确实保持未保存至关闭；后台强制保存单独由服务测试验证。正常窗口关闭和应用退出都在五分钟间隔未到期时执行，注入四百毫秒写盘延迟，确认进程和调试端口真实退出。先从退出后的磁盘精确核对二十三字符与约十六秒，再用重开的公开查询核对总量及明细；启动本身可按原口径产生少量新活动，不当作旧数据重复。测试结束逐字恢复原统计目录并确认无额外文件。

三十三个测试文件、二百三十项测试通过；类型检查、构建、打包及九套宿主验收通过。证据位于构建目录的保存间隔退出验收结果、安装核对及截图文件；不纳入提交。

正式安装：CMBK 零点二十点零，默认六十秒，安装核对全部通过。备份包含旧插件、普通统计目录及完整导出；安装后真实同步连接下实例稳定且配置无重复写入，设置窗口显示值、范围、预设和字体均通过验收。
