# 学习时间轴详细方案

更新日期：2026年11月17日。

状态：待用户审查。日常图表类型、周回顾提供入口及下述前三项功能已确认；本文件中的具体交互默认值、片段结构和实施步骤为拟议方案，批准后才开发。本次不修改源码、安装插件或操作 CMBK。

## 一、定位和范围

学习时间轴回答“某一天，哪些时间在使用哪些笔记或 YOLO”。横轴表示时间位置，轨道按学科组织，色块表示原计时规则已经计入的活动区间。它记录的是活跃使用轨迹，不是专注程度、阅读理解或知识掌握情况。

主入口是常规图表类型“学习时间轴”，可嵌入首页或每日笔记。周回顾提供“查看当天时间轴”，传递日期和目录筛选，进入同一个组件。首版只看单日，不新增学习中心或独立的长期驻留工作区。

| 项目 | 本轮要求 |
| --- | --- |
| 功能一 | 日期选择、前后一天、时间缩放和平移 |
| 功能二 | 学科到笔记的下钻、同篇笔记全部片段高亮 |
| 功能三 | 简洁悬浮提示、固定片段明细、打开笔记、前后片段和同笔记片段定位 |
| 数据基础 | 新增活动区间明细，随原计时事件增减，保留既有小时累计 |
| 旧历史 | 保留原累计；无法定位的历史明确显示为只有汇总，不伪造区间 |
| 字体与图形 | 保留霞鹜文楷、宿主深浅主题，复用现有 ECharts 和 SVG |
| 统计约束 | 原空闲、暂停、累计、小时分桶、多端相加及全局采集范围不变 |

不纳入区间框选分析、任意多日甘特图、周月时间轴、自动会话主题、效率评分、手工修改或补记片段、报告导出、跨端重叠去重。必要的相邻片段合并、重叠呈现和缺口提示属于正确显示数据所需的处理，不扩展为新的分析功能。

新增持久化明细属于数据结构扩展，不能只改前端。拟将完整导出数据版本从十一升级为十二；原统计字段和计算语义保留。原普通文件记录的外层版本机制继续使用，不另建一套同步仓储。

## 二、入口和典型流程

### 日常嵌入

在图表设置中增加“学习时间轴”，仅适用于“活跃使用时长（笔记＋YOLO）”。选择该类型时保留当前目录筛选；不能搭配字数、任务或笔记创建日期，也不把这些数据拼成活动片段。

配置保存图表类型、标题、日期导航范围、目录筛选和初始一级／二级分组。日期浏览、展开轨道、缩放窗口、当前选择和高亮只属于这个图表实例，不写回 YAML、全局设置或统计文件。新建时间轴默认最近三十天作为导航范围；从已有图表切换类型时保留原日期范围，不强行改成三十天。完整日期范围由现有日期配置控制。

初始选择范围内的今天；固定历史范围不含今天时，选择不晚于今天的末日。前后一天、日历和“今天”均受配置范围限制，没有可选日期时显示空态，不反向改写配置。未来无记录日期不能进入；若已有真实超前记录，则允许只读查看并提示日期／时区异常。仅有旧汇总的历史日仍可进入。不同嵌入实例各自维护选择，不能互相切换日期。

区域不足时提供“放大查看”，将当前日期、目录、分组、展开状态、缩放和选择带入更大弹窗。关闭后回到原图，并保留原图状态；普通打开笔记时关闭放大弹窗，修饰键打开保留弹窗。嵌入图自身始终保留。这里的导航范围就是现有图表日期配置产生的查询边界，不另存第二套导航日期。

### 从周回顾进入

在既有“每日记录与参考目标”的所选日期详情中增加“查看当天时间轴”；不改变原来的日期点选和笔记联动。当天只有旧汇总时也可以进入，先解释历史精度。

入口携带所选日期、周回顾当前目录范围及分组基准。日期使用周回顾明确选中的日期，不自动换成今天；所选学科或某篇笔记不隐式取代顶部目录筛选。首版不从热力格额外传入小时框选。

周回顾选中的日期不受任何首页时间轴的配置限制。此次临时图表的导航范围设为所选自然周，未来空日仍不可进入；返回当天或前后日期只在这个临时范围内操作。它不修改首页范围，也不把临时图表保存到笔记。

周回顾在现有弹窗内切换到时间轴详情，使用同一个图表组件，不叠加第二个 Modal。顶部“返回周回顾”恢复原报告日期、快照、滚动位置和焦点；右上关闭按钮关闭整个周回顾。普通打开笔记沿原策略关闭整个宿主弹窗，修饰键打开保留当前详情。

首页放大仍使用单独的临时弹窗。每个窗口只允许一个活动的时间轴大视图，重复入口更新目标并聚焦已有视图，不能生成多层重叠容器。不同窗口互不抢占；“独立窗口”仅指用户已有的 Obsidian 弹出窗口承载嵌入图或报告，不是新增时间轴工作区。

### 查询范围与采集范围

时间轴默认空目录筛选，表示全部已有笔记和 YOLO；明确选择笔记目录时排除 YOLO。支持查看历史上采集过、如今已不在全局采集目录中的记录，遵循周回顾的历史查询语义。

这只改变时间轴的只读查询范围，不增加采集对象。新片段只能来自原采集流程已经接受的活动，不因查看某目录而开始采集该目录。原其他图表的范围校验保持原行为，不能为接入时间轴顺手取消所有图表的现有约束。

## 三、布局和字体

从上至下为日期与缩放工具、时间刻度和学科轨道、精度提示、按需出现的片段明细。首页不堆叠摘要卡片或重复解释；完整口径收在帮助说明，必要缺口短句直接显示。

宽窗明细位于图下方；窄窗同样向下展开，不覆盖图形。轨道多时使用组件内部的纵向浏览，不造成整页横向溢出；横向历史时间由缩放和平移控制。长学科和文件名可截断，完整名称通过简洁提示与明细获得。

组件控件、ECharts 文本、悬浮提示和明细均继承现有霞鹜文楷字体链，不另行替换成系统字体。沿用共用颜色和标题关联方式；禁止重新启用逐项列举内部坐标、秒数和缺失值的长无障碍解说。图表有简短可访问名称，日期与选择可使用原生控件操作。

同一学科颜色稳定，不同笔记通过名称和展开轨道区分。选中、高亮和状态不能只用颜色表示。只在缩放、选择和展开变化时使用短过渡，遵循减少动态效果；无循环动画。

## 四、功能一 日期导航与时间缩放

| 操作 | 拟定行为 |
| --- | --- |
| 日期选择 | 日历、上一天、下一天和回到今天；按本地日历加减日期，不用固定二十四小时毫秒数代替 |
| 初始时间窗口 | 有片段时适配首尾片段，两端各留十五分钟，最窄两小时，边界不超出所选自然日；无片段时按历史状态显示空态 |
| 全天 | 展示该日完整时间轴；不隐藏中间空档 |
| 适配记录 | 恢复到当日已有片段范围；不修改日期或筛选 |
| 放大与缩小 | 提供明确按钮，拟定最窄十五分钟、最宽全天；以当前窗口中心缩放，边界自动限制在当天 |
| 平移 | 通过底部时间导航条拖动；缩放后才能平移，不能跨到相邻日期 |
| 页面滚动 | 默认滚轮继续滚动笔记，不截获整个页面的滚轮作为缩放；窄窗和触屏可完全依靠按钮与导航条 |
| 片段定位 | 前后片段或同笔记片段进入视口时，只作必要平移，不随意重置用户缩放 |

“适配”不压缩空白：08:00—09:00 与 11:00—12:00 之间仍保留两小时空档。色块在视口边缘裁剪时，明细显示原片段完整起止及有效时长；当前缩放只是浏览窗口，不作为时间筛选重新计算总量。

自动刷新保留日期、窗口、展开项、选择和焦点。用户已经放大或平移后，新片段不强行把视图拉回最新时间；点击“适配记录”再重新定位。仅初始跟随今天的实例在跨午夜后切到新一天；主动浏览历史的实例保留原日期，并更新日历边界。

主动切换日期或从周回顾重新进入某一天时，清除旧片段选择和同篇高亮，对新一天重新执行“适配记录”，不把前一天的局部缩放带过来；目录和分组仍保留。新一天只有汇总时进入汇总空态。改变同一天的缩放、展开轨道和固定明细不触发重新适配。

嵌入图首次呈现不抢笔记焦点；首页放大后聚焦日期控件，周回顾内部进入后聚焦“返回周回顾”。日期切换后留在原操作按钮，按钮变为不可用时落到日期控件；缩放与平移后保留操作控件焦点，不强行跳入明细。选中片段被删除时，焦点回到有可选项的片段选择入口，否则回到日期控件。退出键先关闭日历等浮层，再清除固定明细，之后从内部详情返回周回顾或关闭首页放大弹窗；不劫持原生选择控件自身的退出操作。

## 五、功能二 学科下钻与同篇高亮

学科按目录归组，不读取正文、标签或 AI 主题。全部记录且只有一个全局采集根目录时，用该目录作展示基准，基准外历史另列真实目录组；有明确筛选时以筛选目录为基准。一级／二级目录选择与周回顾沿用相同规则，父子目录不重复归属。

默认每个学科一条轨道，显示片段的短笔记名。展开一个学科后，按笔记显示子轨道；再次点击可折叠。展开只影响当前实例，不改变查询范围或顶部累计。

点击某片段后，固定其明细，并高亮所选日期内同一完整路径的全部片段，其余片段弱化但仍可点选。高亮跨越该笔记当日出现过的时间窗口，不局限于当前屏幕。提供明确清除动作；清除后恢复全部片段正常显示。

折叠包含选中片段的学科时保留选择和明细，在父轨道显示相应高亮。主动切日期或目录时清除已不属于新上下文的选择；调整分组层级后按稳定片段身份恢复仍存在的选择。数据刷新不按数组下标恢复。

YOLO 始终独立为“YOLO 对话活动”，不挂在某篇笔记下。不显示模拟预览中的具体对话主题，不采集对话内容、消息或会话编号，也不提供不存在的“打开笔记”按钮。同名笔记按完整路径区分；历史文件删除后仍保留轨迹。

## 六、功能三 片段明细与操作

悬浮只给出完整名称、起止时间和有效时长；点击固定下方明细。悬浮不能覆盖或替换已固定的选择；键盘和触屏可通过片段选择控件获得同样信息，不依赖细小色块命中。

| 明细内容或动作 | 规则 |
| --- | --- |
| 名称和路径 | 笔记显示文件名与完整路径，YOLO 显示独立活动名称 |
| 时间和时长 | 显示起止到秒、有效时长到秒；原始秒数不因格式化改写 |
| 上一段与下一段 | 按本日、当前目录范围内的全部活动排序，末端禁用、不循环，也不自动跳日期 |
| 同笔记其他片段 | 展示该路径本日其他片段的简洁时间列表；点击定位并保持高亮 |
| 打开笔记 | 沿用现有普通／修饰键打开策略，执行前检查文件仍存在；不创建缺失文件 |
| 文件缺失 | 保留明细并标记“文件已不存在”，禁用打开 |
| 清除选择 | 隐藏固定明细，恢复正常轨道；焦点回到原控件或可用的片段选择入口 |

排序以开始、结束和稳定身份依次决定；多来源并发片段都保留，不能按结束时间覆盖其中一段。选择位于折叠区的片段时先展开相应学科，再定位。前后操作与数据刷新保留键盘焦点。

空闲回撤截短选中片段时更新明细；整段被撤销时清除选择并提示“该片段已随空闲回撤移除”，不跳到无关笔记。重命名后继续按身份恢复选择，显示新路径。

## 七、活动片段的计时语义

唯一采集入口仍是现有 TimeTracker 的 add/remove 回调。不监听鼠标键盘另起一个计时器，不读状态栏总量反推增量，也不让图表查询强制结算活动。

| 情况 | 片段处理 | 原累计处理 |
| --- | --- | --- |
| 原流程产生 add | 为同一活动追加或延长片段 | 原 addTimeSpan 照常更新小时桶 |
| 同篇持续活动和十五秒心跳 | 同一连续活动内相邻片段合并，避免每次心跳永久生成一行 | 心跳频率不变 |
| 切换笔记或 YOLO | 原活动按原规则结算，新连续活动使用新身份 | 不改变切换时的结算边界 |
| 未满闲置阈值恢复操作 | 片段保留该间隔 | 继续沿用原保留规则 |
| 达到五分钟默认闲置阈值 | 撤销最后一次有效操作后的已计入尾段，未结算部分不生成片段 | 原 removeTimeSpan 撤回相同尾段 |
| 未满阈值时手动暂停、后台、弹窗、正常退出 | 按原规则结算到中断，结束连续活动 | 不借新图扩大空闲扣除范围 |
| 休眠、长心跳中断、系统时间或时区异常 | 沿原核心的中断与回撤结果，断开连续活动，不跨异常连接 | 不修改原异常判定或补计 |
| 采集关闭、范围外笔记 | 不生成新片段 | 不隐式启用采集或扩大范围 |

示例：最后一次有效操作为 10:00，已结算心跳写到了 10:04:45，10:05 检出闲置。片段和桶都撤回 10:00—10:04:45，未结算的十五秒不绘制；不能保留 10:00—10:05 的色块。若 10:03 已正常暂停，仍按原规则保留到 10:03。以上只是规则示例，不是实际学习数据。

当前尾段中原核心仍视为暂计的部分，可以在本机图中作轻量标记；不在每帧扩展到系统当前时刻。保存过的片段也可能在下一次空闲回撤时修订，不能把“已保存”写成“已最终确认”。远端保存状态不能证明该端已结束活动或所有设备已同步。

打开时间轴、拖动缩放、浏览明细不能被当作宿主笔记的新正文活动。新增组件根节点标为插件自有控件，观察器在匹配 Markdown 正文前识别；沿原暂停／上下文处理，不解除手动暂停。正文正常打开后才按原流程恢复判断，YOLO 独立窗口保持现有采集能力。

## 八、片段结构和连续身份

拟在 timeActivity 内增加可选 timeline 字段，包含自身格式版本、segments 和 recordingPeriods。原 buckets、periods、policyChanges 不删除、不重算。旧记录没有 timeline 是合法情况，不补成“已完整记录”的空集合。

| 片段字段 | 含义 |
| --- | --- |
| id | 新片段的全局随机身份；延长或截短时保持不变 |
| continuityId | 同一次连续活动身份；由核心开始新活动时创建，add/remove 共享；暂停重入、路径切换、重载和异常后重新创建 |
| recordingPeriodId | 对应具备片段记录能力的来源区间；使用随机标识，不持久化真实设备名称 |
| path | 完整笔记路径或现有 activity://yolo-chat 保留键 |
| bucketKey | 对应原小时桶键，包含原日期、小时与时区偏移；不以查看端时区重分桶 |
| start 与 end | 区间左闭右开，使用毫秒时间戳；不存无限延伸的活动末端 |
| seconds | 原事件实际计入的秒数，保留浮点精度；明细不由色块像素宽度计算 |

recordingPeriods 记录随机身份、开始、可选结束及当时目录范围，作为 timeline 元数据一同持久化。新版本每次运行具备记录条件时新建随机区间；手动暂停、禁用、范围变更、挂起、正常退出或替换时沿原覆盖边界结束，恢复条件后新建。正常重载不复用上次运行的未结束身份；意外退出遗留的开放区间按该来源最后保存时刻保守封口，不延长到本次启动。旧身份作为历史保留，不能在每次普通保存时重新生成。

这些区间仅说明何时具备片段记录能力，既不表示期间一直在学，也不证明所有远端数据完整；不代替原时长覆盖 periods，更不作为固定设备身份。

核心仅增加用于标识连续活动的内部身份，不改变 elapsed、闲置阈值或 add/remove 的秒数。移除事件携带原连续身份，只能修改本次运行对应活动，不能从同路径的其他设备或历史记录中扣除。

在原日期／小时／偏移边界拆分基础片段，使其能与桶逐项核对；切分应与原分桶共用等价计算，不能再实现一套稍有不同的时区或舍入规则。同一连续身份、同路径、同桶、首尾精确相邻的心跳延长已有片段。

持久化基础片段与显示色块分开：每个基础片段只有一个 bucketKey；查询层可把同一连续活动的跨小时基础片段临时拼成色块，并保留组成它的基础 id，拼接结果不回写统计。存在真实间隔、不同连续身份或不同来源时不合并成连续活动。

remove 首版只处理现有核心会产生的尾段撤回，按本地同连续身份、同路径从尾部向前处理跨桶基础片段：完全撤回则删除，部分撤回则截短。保留秒数按原事件切分精度计算，不能扣成负值或保留零长片段。未匹配上的撤回标记为明细异常，不从远端或其他连续活动中凑数；不新增任意中间区间删除能力。

基本校验包括身份唯一、合法路径和桶键、有限起止与正秒数、结束晚于开始、与原映射区间长度相符。只允许浮点／毫秒舍入误差；不能接受一秒墙钟区间凭空附带一小时有效时长。校验不因格式化取整修改原桶。

## 九、保存 同步 和数据操作

### 保存与格式

片段进入原 StatisticsData.timeActivity，和本次小时桶一起生成同一份统计快照，经 StatisticsRepository 写到既有统计目录的“记录”文件。沿用随机记录身份、递增 revision、generation 和退出同步检查点；不写到高频插件 data.json，不新增独立片段写入队列。

完整导入／导出拟使用 schemaVersion 十二，附加 timeline 自身格式版本为一；普通统计记录外层 formatVersion 仍为一。三者分别表示整份数据、可选明细和仓储信封的格式，不是三套计时规则。读取现有无片段记录时保留原统计，不批量改写 legacy 或所有历史文件。

| 格式边界 | 升级要求 |
| --- | --- |
| 数据和默认结构 | 更新 EditActivityStore、EMPTY_EDIT_ACTIVITY_STORE 与规范化上限到十二；继续读取原本支持的一至十一版本，不重算旧桶 |
| 配置快照 | configurationSnapshot 的 schemaVersion 同步改为十二，settings、graphThemes 和 storage 目录值保留；不能只改导出版本而漏掉初始化 |
| 原普通文件 | 外层记录格式仍为一；timeline 缺省合法，新增字段由完整的复制／验证链处理，不改历史记录身份或 revision |
| 完整导入与备份 | 新格式携带区间；旧格式缺少区间就保持缺失。首次写入新格式前通过既有备份机制保存原配置和统计，失败不继续部分升级 |
| 旧程序与降级 | 不保证旧程序识别十二版配置或完整导出。保留新旧原始备份，不通过改版本号或删除明细字段伪装旧格式后覆盖正式数据 |

该版本扩展尚待本方案审查，不在文档阶段迁移任何现场数据。后续安装或回退必须单独核对实际版本、备份与数据，不能把只回退程序视为已经验证新明细可继续写入。

规范化、深拷贝、合并、只读缓存、导出、备份、恢复、重命名和替换入口都必须接入新增字段。当前 cloneTimeActivity 仅复制三项旧字段，不能遗漏这里后只把片段挂在运行内存中。

日常保存间隔、重试规则和退出原子保存沿用现有机制。桌面关闭时片段随桶一起保存并封存旧队列；移动端保持原异步适配的实际能力，不承诺强制结束进程仍零丢失。意外退出只恢复最后成功保存的区间，不延长到重新启动时刻。

### 合并与冲突

先由原仓储按记录身份选择最新 revision，再合并当前 generation 的各来源。旧版本片段不是增量事件，不能再把同一记录的多份 revision 相加。

片段按全局 id 识别；同 id 相同内容只保留一次，不同来源的不同 id 全部保留，包括同时段、同路径的活动。若当前有效记录中出现相同 id 不同内容，标记明细冲突，不按较长区间或较新时间擅自猜测，也不据此修改桶。

桶仍按原规则相加。片段只是定位信息，不能再加入桶或日累计。同步读入后只使受影响的日期和实例失效，不能为刷新图表调用 exportData；现有 exportData 会 checkpoint，不是纯查询。

### 重命名 删除 导入 与清空

| 操作 | 必须保持的结果 |
| --- | --- |
| 笔记或目录重命名 | 原桶和片段使用同一路径映射，片段 id 不变；远端记录沿原 rename 目标与顺序生效，YOLO 保留键不改 |
| 活动中重命名 | 原流程结算和上下文切换后，回撤仍能关联原连续身份；不得重新写出悬空旧路径 |
| 删除笔记 | 保留历史统计和片段，查询时标记文件缺失 |
| 导入含新明细的数据 | 严格校验后沿原整份替换、自动备份和新 generation 处理，旧缓存与临时选择清除 |
| 导入只有旧汇总的数据 | 保留其累计，不沿用导入前片段填充它；该历史重新呈现为只有汇总 |
| 清空和恢复备份 | 桶、片段和记录能力区间一起服从替换边界，不留旧 generation 的轨迹 |
| 备份失败或替换冲突 | 沿原保护停止操作，保留上次有效数据；不把“只清片段”当作成功替换 |

原统计字段校验不能放宽。若仅附加明细损坏，自动读取应隔离有问题的明细、明确提示缺口并保留来源文件及原桶，不把它画成确定记录；显式导入损坏的新格式则整次拒绝，替换前数据不变。隔离与错误标记必须可追溯，不能静默修复时间或吞掉整份统计。

## 十、旧历史和混合数据的呈现

小时桶只知道“某小时某篇笔记累计多少秒”。例如 09 时桶有二十分钟，既可能发生在 09:00—09:20，也可能分散在该小时，无法倒推出位置。禁止平均铺满整小时、贴到整点、由文件修改时间补齐或用覆盖区间生成活动色块。

每份当前有效统计记录、原桶键和路径先核对累计秒数 B 与可用片段秒数 S，再按所选日期和目录汇总。这里的“来源”指仓储已选出最新 revision 的统计记录，不要求给原 TimeBucket 增加设备 ID；一份导入替换记录可以包含多个匿名记录能力区间。

核对发生在仓储合并各来源的桶之前，复用原 generation 选择、最新版本、远端封口及重命名处理，再在只读投影中汇总精度结果。现有 read(local) 只返回合计，需要补充共用有效来源投影；不能先把来源信息丢掉，再从合计反拆每个来源，也不能复制第二套版本选择算法。这样可避免某个来源片段过多、另一个来源只有旧汇总时，错误地把两者凑成“完全可定位”。比较使用微秒级浮点容差，界面分钟显示值不参与校验。

| 状态 | 判定和界面 |
| --- | --- |
| 只有汇总 | 有正时长但没有可用片段，显示“当天有已记录时长，但历史仅有小时汇总，无法还原片段”，不画虚构色块 |
| 部分可定位 | 部分时长有片段，绘制这些片段，同时显示“已有部分记录无法定位”；按需列出全天累计、可定位和未定位量 |
| 已有时长均可定位 | 对应正时长桶与片段核对相符；只表示已有累计有位置，不表示全天已完整采集或全端已同步 |
| 无已记录活动 | 原累计为零且无有效片段，显示未见记录；结合原覆盖提示，不把缺失解释为确定零投入 |
| 未来日期或时间 | 不生成未来活动；超前日期已有真实数据时保留并提示日期／时区异常，不静默挪动 |
| 明细异常 | S 大于 B 超出容差、冲突或损坏时提示无法完整核对；不缩短、复制或拉伸片段来凑齐总量 |

仅在无异常且 S 不超过 B 时，B−S 才称为“未定位时长”，不是未学习或丢失时长。异常时不显示负数缺口，仍以原桶报告累计，不输出“全部可定位”。

例：当天桶累计九十分钟，其中升级后片段三十分钟，旧历史或旧端贡献六十分钟。时间轴只绘制三十分钟，提示另外六十分钟只有汇总；不能把九十加三十显示成一百二十分钟。

当天中途升级、旧端继续写入、同步只到达部分来源时都可能混合。不能凭“日期晚于本机升级日”认定精度完整，也不能用每个设备的“安装时间”填补记录。recordingPeriods 用于解释来源能力，不取代逐桶核对。

仅有汇总时提供“查看小时汇总”，复用现有学习时段的单日视图，携带相同日期和目录；不把小时柱当作精确片段塞进时间轴。旧历史仍可在热力图、小时图和周回顾按原口径查看。

只有汇总或无已记录活动时，片段选择、前后片段、同篇列表、打开选中笔记和缩放轨道不显示为可用动作；日期导航与已有汇总入口仍可用。混合数据下这些操作只针对真实、可定位的片段，不能把未定位时长插入前后顺序。旧汇总中的笔记仍可通过既有小时明细查看和打开，不因此丢失原笔记入口。

## 十一、多来源 时区 和数据量

不同来源同时活动时，在对应学科／笔记轨道内分成并行子行，或以可展开重叠组呈现，确保每个片段都能选择。不能用后画的矩形遮住前一个，也不能把两个来源拼成一个更长的学习段。来源只作匿名区分，不能根据随机记录身份推断“电脑”或“手机”。

日期、小时和时区偏移沿原记录解释，按原 bucketKey 的日期选择该日；不因查看设备换了时区而重写历史。色块的钟面位置用记录时偏移计算。不同偏移落到同一钟面位置、夏令时重复小时等情况保留并行和偏移说明，不连接成不存在的连续区间。

跨午夜的同一活动按原边界拆成两天，本图只展示所选日部分；跨小时且真实相邻的部分可以在显示层拼接。墙钟发生回拨或跳变时沿原计时中断，不绘制负宽矩形或跨过异常空档。

首版不自动删历史，也不设静默“最近若干天才保留片段”的期限。通过连续心跳合并、单日查询缓存、只渲染当前日期及可见轨道控制成本。不得每十五秒永久落一份片段文件或为每个片段创建独立文件。

实现阶段用合成的一年数据核查内存、快照大小和单日交互；保留现有单文件一百兆字节保护，不擅自提高上限。如果区间数据增长使同一记录写入明显不可接受，应在实施审查中提出明确的分区设计，不能先静默截断片段、另加无审查仓储或牺牲原桶保存。

## 十三、分步实施和必要验收

批准后分三步交付，每步可独立核对；不在本次方案编写阶段动手实现。

1. 活动片段与旧历史查询 → 验证相同事件序列下桶和原实现逐项一致，片段增减、持久化、混合历史与替换正确。
2. 常规时间轴与前三项交互 → 验证日期缩放、学科下钻、高亮、明细及笔记打开，并检查多实例与自有控件不误计。
3. 周回顾入口和安装准备 → 验证日期／目录传递、弹窗返回、真实旧历史空态及发布数据核对；只有用户后续授权安装时才操作正式库。

验收以公共行为为准，将有状态边界先写成可失败测试，再实现。复用已有测试文件和宿主脚本；不为每个标签或 CSS 属性单独写镜像测试，不重复真实等待五分钟，采用可控时钟。

| 编号 | 验收标准 | 最小验证方式 |
| --- | --- | --- |
| A1 | 同样的 add/remove 序列，开启片段记录前后日／小时／路径累计一致，精度误差小于百万分之一秒；暂计不重复加入 | 片段模型与原分桶对照测试 |
| A2 | 五分钟闲置回撤、未满阈值恢复、正常暂停和睡眠中断分别遵循原规则；不撤远端同路径片段 | 复用 tracker 可控时钟，组合覆盖 |
| A3 | 跨小时／午夜／偏移、连续合并与真正空档处理正确，无负长或零长片段 | 纯模型边界测试 |
| A4 | 保存重载、同记录多 revision、同步重复与多来源重叠不重复累计、不丢片段 | 原仓储测试扩展 |

| B1 | 表单与 YAML 都能创建时间轴，非 TIME_ACTIVITY 明确拒绝；当前目录设置不变 | 配置测试与隔离宿主 |
| B2 | 日期、全天／适配、缩放／平移、刷新保留视图；浏览历史跨午夜不跳回今天 | 隔离宿主真实交互 |

## 十四、审查时需要确认的具体选择

产品定位、前三项功能、字体和统计约束已确认。本方案建议采用以下细节，审查通过后作为实现基线：

1. 首版只看单日，缩放十五分钟至全天；日期导航范围可配置，默认最近三十天，既有范围不强行覆盖。
2. 首页嵌入和周回顾入口共用组件；首页放大使用临时弹窗，周回顾在原弹窗内部切换并返回，不叠第二层容器，不新增长期驻留页面。
3. 学科轨道默认折叠到一级，支持一级／二级目录及笔记子轨道；同篇高亮范围为所选日期。
4. 新区间通过原 add/remove 回调记录到原普通统计文件，完整导出版本拟升为十二，不改计时口径。
5. 旧历史保持小时精度；混合日只画真实片段，未定位时长另作说明，旧累计和周回顾继续可用。
6. 不增加手工编辑、框选分析、自动主题或重叠去重，也不自动删除历史。

主要成本和风险集中在持久化字段的完整接线、空闲回撤、不同来源混合及退出保存；它不是只增加一个图表 renderer 的小改动。若实现时发现这些边界需要改变原统计规则或另建存储架构，须先修订本方案并重新确认，不能借时间轴功能直接改变原累计。
