更新日期：2026年11月16日。

状态：用户已确认实施，零点二十二点零已实现并完成独立验收，记录见文末。随后按用户指令安装到正式 CMBK 并重载，安装记录见文末。本方案只展开[功能完善规划](功能完善规划.md)的第二项；第一项已完成，其余项目不随本方案推进。

## 目标与交付范围

周回顾回答三个问题：这一周记录了多少学习投入，主要投入哪些学科和笔记，与上一周相同进度相比有哪些变化。学科按文件夹分组，时长仍是现有交互规则估算出的活跃使用时长，不代表注意力、知识掌握程度或学习效率。

首版交付五项内容：七天每日趋势、学科时长分布、投入最多的笔记、按本次参考目标计算的达标情况，以及日期范围明确的上周同期比较。只分析时长，不混入字数，不新增统计采集、数据格式或同步规则。

首版采用独立命令和宿主弹窗，打开时生成快照，提供手动刷新。周回顾不写入笔记、不自动生成周报、不加入导出、搜索、任意排序、手工补记或精确会话。这些分别属于后续规划，避免把本项扩展成新的统计工作台。

## 入口与浏览流程

时长图标题增加“周回顾”按钮，左侧功能区提供日历图标；保留命令“查看学科周回顾”，三个入口共用当前窗口的报告。时长采集关闭时也能查看已有历史，不隐式开启采集；没有历史时仍能打开，说明“暂无时长记录，开启时长统计后才会积累数据”。

进入弹窗默认定位本周并选择“全部已有记录”，汇总已记录的笔记和 YOLO 时长；不随全局采集目录数量改变，不修改全局采集范围，并在顶部清楚显示该范围，不从当前笔记猜测学科。全部已有记录采用仓库根目录作为分组起点，界面简称“全部记录”，具体口径收在统计说明；例如所有医学笔记都在“临床医学”下，会先汇为一个分组，用户可选择“临床医学”根目录进一步查看各科。

顶部用紧凑日期范围连接“上一周”“下一周”和现有日历控件，浏览历史时提供“回到本周”。选中某日后定位它所属的自然周，不改变周的起始星期。当前周的“下一周”禁用；最早可浏览周由已有时长桶日期或覆盖记录起点决定，覆盖但零活动的早期周也能查看。没有历史时只提供当前周。比较用的前一周即使早于可浏览范围，也要返回缺失状态，不能当成零。

根目录选择器包含当前仓库文件夹和历史时长路径对应的父目录，提供搜索，优先列出当前采集根目录，其余按完整路径排序，并按完整路径区分同名目录；搜索文字本身不改变范围。历史上存在、当前已删除的目录标记“已不存在”，仍可只读查看；切换筛选不修改全局采集范围。周回顾允许查看当前采集范围以外的已有历史，因此不能直接套用现有图表“必须位于当前全局采集范围内”的限制。

“一级分组／二级分组”、根目录和参考目标仅本次弹窗有效，关闭后重开恢复默认值，不写入插件配置、同步数据或图表代码块。重复执行命令时，当前窗口已有弹窗则聚焦它，不叠加同一窗口的多个实例。

学科分布展示所有有正时长的分组，不将末尾项目合为无法追溯的“其他”；列表随弹窗纵向滚动。重点笔记固定展示前十，不增加搜索、排序切换或全量笔记浏览入口。点击学科只改变重点笔记列表，概览、每日趋势和同期对比仍对应顶部根目录，列表上方的筛选标签明确显示当前学科并提供清除动作。

点击笔记沿用现有打开逻辑，支持修饰键打开。普通打开后关闭周回顾，让用户回到正文；没有文件的条目不创建空白笔记。仅查看弹窗、切周、切学科或刷新不能被当成正文活动。打开弹窗沿用宿主既有暂停规则，关闭后也不能解除用户已有的手动暂停。

宽窄窗均使用七列趋势，保持日期顺序，不产生整页横向滚动。长目录候选可换行，笔记路径弱化截断并保留完整可访问名称。所有按钮、目录选择、目标输入、日期选择和学科行可键盘操作；退出键关闭弹窗并恢复原焦点，日历或目录搜索打开时先关闭对应控件。状态不能只靠颜色区分。桌面窄窗检查不替代实体手机验收。

## 日期范围与同期比较

### 自然周和本周累计

选择日期所在周的周一为起点，下一周周一为不包含的终点，界面显示周一至周日。日期加减按本地日历推进，不使用固定毫秒数模拟七天，以免跨夏令时日期错位。

历史周累计包含完整七天；当前周累计包含周一至快照生成时刻已有的记录。今日标记“进行中”，没有记录的未来日期显示“尚未到来”，不参与有记录天数、达标计数和比较分母。周回顾固定周一开始，不继承其他图表的 `startOfWeek`，也不改变原“一周节奏”的“所选日及前六天”语义。

历史时长按原记录的日期键汇总，不随当前时区重新分桶，也不把多端同时发生的活动去重。更换系统时区或不同设备使用不同时区时，报告仍解释为“按各记录原日期汇总”，不能声称全部设备按当前时区统一结算。若本机视为未来的日期已有正时长，保留数值并提示“日期超前，覆盖无法确认”；这些记录纳入所选周总量、分组及有记录天数，概览明确提示包含日期超前记录，但不参与目标和同期比较，不静默丢弃或移动日期。

### 当前周与历史周的比较区间

当前周只比较周一至昨日，对照为上一周相同星期范围。例如在二零二六年十一月十八日星期三查看：主累计包含十一月十六日至十八日的现有记录；比较区间为十一月十六日至十七日，对照十一月九日至十日。今天的记录另显示为“今日进行中，不参与同期比较”。这些日期只是口径示例，不是用户实际统计。

星期一尚无已结束日期，显示“本周尚无已结束日期，明日起可比较”，不拿今天的一小段与上周整日比较。历史完整周则与它前面的完整七天比较，区域标题使用“历史周对上一完整周”。星期日查看当前周时，比较仍只到星期六；到下周后，该周作为历史周才进行完整周比较。

首版不提供“上周同一分钟”“上周同一小时进度”或整周预测，不按经过时间比例切分历史小时桶。

### 差值与百分比

双方总量都由各自明确区间内的原始秒数相加得到。先判断覆盖和采集口径，再决定能否显示变化率。覆盖按下节明确的本机日界解释，不声称还原原设备的历史日界。

口径检查必须使用原始覆盖与阈值变更记录，不能只看有时长行的 `policyChanged`。将重叠覆盖区间的目录集合规范化成范围签名，保留空集合表示的全范围与具体目录的区别；对照起点到本次比较终点之间，若发现不同范围签名、范围变更或空闲阈值变更，保守标记“比较口径可能不同”。这段检查包含两段比较之间的间隔，避免漏掉发生在上周后半周的规则调整；证据缺失时标记“口径无法确认”。

| 条件 | 呈现规则 |
| --- | --- |
| 双方日期均有覆盖证据、覆盖完整，且没有发现比较口径变更 | 展示双方已记录时长及差值；对照大于零时展示 `(本次－对照)÷对照` |
| 对照为零且有完整覆盖证据，本次大于零 | 显示“上期已采集但无活动，本期新增已记录时长”，显示差值，不显示无穷增长率 |
| 双方均为有覆盖证据的零 | 显示“已记录时长持平”，不计算 `0÷0` |
| 任一侧部分采集、未采集或覆盖不可确认 | 并列双方已记录量和缺口，显示“记录不完整，暂不计算变化率”，不输出升降结论 |
| 期间调整采集范围或空闲阈值，比较口径可能不同 | 并列原值并说明变更，不据此计算增长率或推断投入变化 |

差值和百分比使用原始秒数计算，最后格式化；百分比保留一位小数。极小非零差值若舍入为零，显示约等于零，不显示带方向的负零。比较标题始终写“已记录时长”，不写“效率提高”或“学习退步”。

## 每日状态与目标计算

### 补齐七天与覆盖提示

现有时长查询只返回有正时长的日期，查询缺行不等于零活动。必须先生成周内七天，再结合覆盖记录为没有时长的日期补齐状态。

| 数据情况 | 每日显示 | 是否计入时长合计 |
| --- | --- | --- |
| 未来日期且没有记录 | 尚未到来 | 否 |
| 未来日期已有正时长 | 保留数值，标“日期超前，覆盖无法确认” | 是，沿用原日期归属，不参与目标和同期比较 |
| 过去日期有覆盖且覆盖完整、没有活动 | 零分钟 · 已覆盖 | 以零计入 |
| 只有部分覆盖 | 已记录数值或零，并标“部分采集” | 保留已记录秒数，缺口不补零 |
| 无覆盖且无活动 | 未采集 | 不把未知量解释为零 |
| 有正时长但缺少可解释的覆盖记录 | 保留数值，标“覆盖无法确认” | 是，但不据此认定完整采集或计算变化率 |
| 今日 | 已记录数值及“进行中”，另附覆盖提示 | 是，包含现有查询中已计入的暂计尾段 |

单根目录筛选可复用现有覆盖区间合并逻辑。空目录筛选在既有代码中表示“全部已有记录”，其覆盖状态只说明当时存在采集开启的范围，不能证明整个仓库、所有学科或所有设备都已完整采集。此时显示“按当时采集范围”，并检查对比区间的范围是否一致；学科行不继承总体的“完整覆盖”结论，不新增学科覆盖率。

覆盖记录是采集开关与范围的证据，不是文件已全部同步的证明。首版统一用查看设备在报告生成时采用的本地时区规则，生成各日期的零点与次日零点，再对覆盖区间求并集；顶部说明“时长按原记录日期汇总，覆盖按本机日界判断”。零活动日只有在这些边界下确有覆盖证据时才显示“零分钟 · 已覆盖”，并不声称证明了原设备的历史全日覆盖。

遇到以下可检测情况，将有关日期的覆盖结论降为“无法确认”：同日桶出现不同偏移；桶的日期、小时和偏移换算出的时刻与本机该日期小时不一致；本机当日两个零点的偏移不同；已有正时长却找不到相应范围的覆盖记录。不能从现有记录判断的跨时区情形，保留“不代表原设备历史日界”的限制，不伪造时区身份或自动重排历史。首版不修订旧图表覆盖算法，也不承诺还原跨时区的精确自然日。

### 本次参考目标

独立命令不对应某张图表，不能自动读取用户在任意一张图中填写的每日目标。弹窗默认六十分钟，标为“本次参考目标”，允许输入正的安全整数分钟；清空后显示“未设置目标”。非法值在输入处提示，不把上次合法值静默当作当前值，也不产生非数结果。

目标作用于顶部所选根目录的每天总时长，不对每个学科分别应用。调整目标只重新计算本次报告，不修改原图表目标或历史统计。界面写“按本次目标”，不声称“达到当时目标”。

先排除未来日期，再判断目标；设某日已记录秒数为 `S`、参考目标分钟数为 `G`，以 `S / 60 >= G` 判断是否已达到目标，避免先取整分钟再比较。

| 日期条件 | 目标状态 |
| --- | --- |
| 已记录量达到目标，哪怕采集不完整 | 已达标；同时保留部分采集或覆盖无法确认提示 |
| 历史日有完整覆盖证据且低于目标 | 未达标 |
| 历史日部分采集或覆盖无法确认且低于目标 | 无法判定；不能说“未达标” |
| 今日低于目标 | 进行中，不提前判为未达标 |
| 无记录且未采集 | 无法判定 |
| 未来日期，包括日期超前的已有记录 | 不参与 |

顶部直接列出“已达标几天、未达标几天、无法判定几天、进行中几天”，各类互斥；已达标的今天只归已达标，不再重复计为进行中。不展示容易掩盖未知日期的单一达标率。未设置或目标非法时，隐藏目标判断，保留时长报告。首版不增加日均指标，避免把未采集日期补零或使用不明确的分母。

## 学科归属与重点笔记

### 文件夹归组算法

先对根目录和路径做已有的分隔符规范化，再按完整目录边界匹配；选择“内科”不能误纳“内科学”。仅按时长统计中保留的路径分组，不通过扫描当前文件夹内容决定历史是否存在。

去掉根目录前缀及文件名后，一级分组取剩余第一段目录，二级分组取前两段目录；不足两段时保留已有段数。同一篇笔记在当前层级只能归入一个分组，不同时累加到父目录和子目录。没有剩余目录段的笔记归为“根目录直属笔记”，采用独立内部标识，避免与真实同名目录混淆。

以根目录“临床医学”为例，以下均为路径示例：

| 路径 | 一级分组 | 二级分组 |
| --- | --- | --- |
| 临床医学/内科学/循环系统/心衰.md | 内科学 | 内科学/循环系统 |
| 临床医学/内科学/总论.md | 内科学 | 内科学 |
| 临床医学/外科学/总论.md | 外科学 | 外科学 |
| 临床医学/学习安排.md | 根目录直属笔记 | 根目录直属笔记 |

“全部已有记录”用仓库根目录应用同一算法，不同时为每个全局采集根另造分组再合并。目录名只是分组依据；不将文件夹名称自动解释为可靠的医学学科分类。

方案确认前新增的 YOLO 计时沿用既有独立归类：选择全部已有记录时，YOLO 纳入总量与每日趋势，单列“独立活动”，不归到学科或重点笔记；选择具体根目录时排除它。目录候选和笔记打开逻辑不将保留来源键当成文件路径。

### 排序与总量约束

分组与笔记按原始累计秒数降序，时长相同时按完整路径稳定排序。学科占比以本周所选范围内已记录总秒数为分母，分母为零时不显示占比或空饼图。保留原始秒数，仅显示时格式化；百分比独立四舍五入可能合计为百分之九十九点九或百分之一百点一，必要时标注“约数”，不修改原数凑整。

必须满足：七天每日原始秒数之和、全部学科与独立活动分组原始秒数之和、全部笔记与独立活动原始秒数之和，均等于本周所选范围总量，数值核对容许浮点舍入误差。前十笔记只是子集，标题写“投入最多的十篇”，不暗示它们之和等于全部投入。正数不足一分钟沿用“少于一分钟”口径，不展示为零。

沿用现有重命名机制：已迁移到新路径的历史随当前路径归组，不新增“当时学科目录”的历史快照。笔记或目录删除后仍保留统计；文件存在性只影响打开操作，不影响汇总。同名笔记按完整路径视为不同项目，不通过名称合并。

## 快照刷新与异常处理

每次打开、切周、切根目录和点击刷新时，从服务读取一次一致的统计视图及生成时刻，供概览、每日、学科、笔记和同期比较共同使用。快照包含本机已计入内存的活动及已经读入的其他运行记录，不只读取磁盘，也不主动等待网络同步；来源未到齐时仍可能稍后变化。

分组层级、学科选择及目标调整只在当前快照上重算，不触发保存或网络操作。快照只包含报告生成时已经进入时长桶的秒数：已经进入桶、尚可回撤的暂计尾段包含在合计里；最后一次结算到报告生成之间尚未进入桶的间隔不补算。不能把状态栏的本机暂计再次相加，也不为使报告精确到生成瞬间而主动结算；不尝试据本机暂计判断远端是否还有可撤回尾段。

弹窗不自动订阅统计事件、不启用额外心跳、整点或午夜定时器。生成时间及“点击刷新获取最新记录”始终可见；跨午夜、导入、清空、恢复、重命名或同步后，报告仍明确代表上次快照，下一次刷新才替换整份报告，不能拼接旧排行与新概览。本周标签、未来日和目标状态也按快照时刻解释；刷新跨周时，跟随本周模式进入新周，用户手选的历史周则保持原周。

点击已重命名或已删除的旧快照路径前重新检查文件是否存在。刷新失败时保留上一次成功快照并标明“刷新失败，当前为上次结果”；首次读取失败只显示错误与重试入口，不能伪装成无数据。目标输入、目录路径和日期标签使用文本节点呈现，不将笔记名称当作 HTML。

关闭弹窗释放自身 DOM 事件、日期控件及实例引用。插件卸载时关闭它，禁止继续读取已卸载的服务；查询和展示不调用结算、暂停切换或保存入口。宿主观察器因弹窗正常触发的暂停与结算仍沿用原行为，不将这种既有行为误报为报告查询修改统计。
